## 1. 設計理念

IRMS 是**病患邊做動作邊瞄一眼**、**治療師事後要信得過**的臨床儀器。三條原則,衝突時依序優先:

1. **狀態先於數據**:畫面第一件要回答的是「現在安全嗎、做對了嗎、下一步是什麼」,
   數值與圖表是證據層,排在後面。
2. **遠看得懂**:主指標、次數與警報在約 2 公尺外可辨識;不能只靠顏色傳達狀態。
3. **安靜,直到需要注意**:正常狀態下畫面低彩度、少動態;顏色與動態保留給真正需要注意的事,
   讓警報出現時不會被日常的裝飾稀釋。

與 beta8 的關係:保留 beta8 的**結構**(固定命令軌、情境命令列、只有工作區捲動、原生標題列、
連續工作面),替換的是**語言**——調色、字級、狀態語意與 Dashboard 構圖。

## 3. 色彩

### 3.1 語意規則(比數值更重要)

| 角色 | 只用於 | 絕不用於 |
|---|---|---|
| **accent(藍)** | 選取狀態、焦點、主要操作按鈕、連線成功 | 表示「做對了」 |
| **success(綠)** | 主指標在目標區、保持中、完成一次 | 一般按鈕、裝飾 |
| **warning(琥珀)** | 需要注意但非危險:未校準、重連中、數值過期 | 超限 |
| **danger(紅)** | 只有兩件事:超過安全上限、硬體錯誤 ERR | 刪除以外的一般操作 |
| **series(紫/青/桃)** | 圖表與姿態視圖的大腿/小腿/Roll 系列 | 任何狀態語意 |

> **修正 beta8 的一個語意衝突**:舊版 `--color-thigh = --color-warning`、`--color-shin = --color-success`,
> 圖表裡的大腿線與「警告」同色、小腿線與「達標」同色。v2 的系列色與狀態色完全分開。

### 3.4 非色彩訊號(原則 2)

- 三條系列線的亮度彼此接近,灰階下無法只靠顏色分辨 → **線型區分**:大腿實線、小腿虛線 `6 4`、Roll 點線 `2 3`;
  圖例同步顯示線型。
- 目標區、保持、超限、ERR 各有**文字標籤與圖示**,且邊框粗細不同(§6.2),灰階截圖仍可區分。

## 4. 字體與字級

沿用已自架的 **Inter Variable**(介面文字)與 **JetBrains Mono Variable**(數值),不增加新的字型管線。
中文由系統字型(Microsoft JhengHei UI)承接,字重對齊 Inter。

所有數值一律 `font-variant-numeric: tabular-nums`,即時跳動時寬度不晃。

| Token | 字級 / 行高 | 字重 | 字型 | 用途 |
|---|---|---|---|---|
| `display-focus` | 160 / 1.0 | 600 | Mono | 專注模式的主指標數值 |
| `display` | 104 / 1.0 | 600 | Mono | 一般模式的主指標數值 |
| `numeric-l` | 56 / 1.0 | 600 | Mono | 次數 (reps)、保持秒數 |
| `alert` | 32 / 1.2 | 700 | Inter | 警報/阻斷標題(「超出安全上限」「裝置未連線」) |
| `title` | 24 / 1.25 | 600 | Inter | 動作名稱、工作區標題 |
| `coach` | 22 / 1.35 | 500 | Inter | 教練提示句 |
| `heading` | 17 / 1.35 | 600 | Inter | 區塊標題 |
| `body` | 15 / 1.5 | 400 | Inter | 一般文字 |
| `label` | 13 / 1.4 | 500 | Inter | 欄位標籤、次要資訊 |
| `micro` | 12 / 1.35 | 500 | Inter | 單位、刻度;**全 App 最小字級,不得更小** |

**距離可讀依據**:以 24 吋 1080p(約 92 ppi)為基準,JetBrains Mono 大寫字高約 0.73 em,
`display` 104px 的數字字高約 76px ≈ 21mm。依標示設計常用的「每 10 英尺視距需 1 英吋字高」
(約 8.3mm/公尺)經驗值,可支撐約 2.5 公尺;`numeric-l` 56px(字高約 11mm)約 1.3 公尺;
專注模式 160px(字高約 32mm)約 3.8 公尺。筆電螢幕 ppi 較高、實體字高較小,這正是專注模式存在的理由。

## 5. 間距、圓角、邊框、層次

- **間距階層(4px 基準)**:4 · 8 · 12 · 16 · 24 · 32 · 48。工作區外距 24,面板內距 16/24,相鄰控制項 8。
- **圓角**:面板 4px、控制項 4px、狀態徽章 2px。沒有膠囊形狀、沒有大圓角卡片。
- **邊框**:一般 1px `border`;可操作控制項 1px `control-border`;**狀態邊框 4px**(只在左緣或整圈,見 §6.2)。
- **陰影**:只有浮動層(下拉選單、對話框、Toast)使用 `0 8px 24px rgb(0 0 0 / 0.18)`(低光主題 `0.45`)。
  **移除 `glow-accent` / `glow-success` 光暈**——那是 beta8 前「Data-Console」調性的殘留。

## 6. 動效

### 6.1 Token

| Token | 值 | 用途 |
|---|---|---|
| `motion-fast` | 120ms `cubic-bezier(0.2, 0, 0, 1)` | 狀態色切換、hover、分頁指示條 |
| `motion-base` | 200ms `cubic-bezier(0.2, 0, 0, 1)` | 面板顯隱、對話框進場 |
| `motion-exit` | 150ms `cubic-bezier(0.4, 0, 1, 1)` | 關閉、離場 |
| `motion-data` | 80ms `linear` | 量表進度弧與數值跟隨(= `UI_SYNC_MS` 80ms,插值剛好填滿一個同步週期,不製造延遲) |

- **禁止**:回彈 (overshoot)、縮放進場、視差、裝飾性循環動畫。取代舊 `--motion-ease-mechanical`(0.16,1,0.3,1 的「急停」曲線)。
- **警報是唯一允許循環的動畫**:4px danger 邊框以 **1Hz** 在 100%/40% 不透明度之間漸變(不是閃爍);
  遠低於 WCAG 2.3.1「每秒 3 次閃光」上限。背景色、文字**不閃**。
- **`prefers-reduced-motion: reduce`**:所有動效改為 0ms;警報改為靜態 4px 邊框 + 圖示,仍可辨識。

### 6.2 狀態邊框

| 狀態 | 主面板邊框 | 底色 |
|---|---|---|
| 正常 / 待機 | 1px `border` | surface |
| 在目標區 | 左緣 4px `success` | surface |
| 保持中 | 整圈 4px `success` | success 12% tint |
| 超限警報 | 整圈 4px `danger`,1Hz 漸變 | danger 12% tint |
| 警報已靜音 | 整圈 4px `danger` **虛線** `8 6`,不動 | danger 12% tint |
| 硬體 ERR | 整圈 4px `danger`,不動 | danger 12% tint |
| 未校準 / 重連中 / 數值過期 | 左緣 4px `warning` | surface |

## 7. 外殼 (Shell)

- **命令軌**:維持 84px 固定寬;底色 = `canvas`,與工作區 `surface` 形成一階落差(取代獨立的 `--sidebar-*` token 組,刪除)。
  選取項:左緣 3px `accent` + `accent` 10% tint 底 + `text` 字色;未選取 `text-dim`。
  標籤取自語言檔短名(繁中:**監測 · 動作 · 紀錄 · 設定**;英文:Monitor · Actions · Sessions · Settings)。
- **命令列**:72px。左:`01` 編號(`label`, `text-muted`, Mono)+ 工作區全名(`title`);
  中:裝置狀態膠片(見下);右:**專注**切換(僅監測工作區顯示)、主題切換、連線按鈕。
- **裝置狀態膠片**:圓點 8px + 文字。已連線 `success` 實心點「已連線」;重連中 `warning` 空心點 +
  「重連中 2/5」+ 既有進度細條;未連線 `text-muted` 空心點「未連線」。**不再用 accent 表示連線**,
  讓 accent 回到只表示「選取/可操作」。
- **示範模式橫幅**:保留全寬、不可關閉;改為 `warning` 12% tint 底 + 左緣 4px `warning` + 45° 斜紋
  (`repeating-linear-gradient`,8px 間距、4% 不透明度),截圖時一眼可辨。

## 8. Dashboard(即時監測)——以狀態為中心

### 8.1 狀態(`DashboardMode`)與優先序

由上而下,**先命中者勝**(與現行 `hintText` 優先序一致,只新增未校準/靜音/過期三個顯性狀態):

| # | 狀態 | 類型 | 主面板呈現 |
|---|---|---|---|
| 1 | 硬體 ERR | 阻斷 | 阻斷面板:`alert`「感測器異常」+ 說明 + 無按鈕(等待自動復原);ERR 邊框 |
| 2 | 協定不支援 | 阻斷 | 阻斷面板:「此協定尚未支援」+ 按鈕「前往設定」 |
| 3 | 未連線 | 阻斷 | 阻斷面板:「裝置未連線」+ 主要按鈕「連線裝置」(與命令列同一動作) |
| 4 | 重連中 | 警示 | 量表照常,數值以 `text-muted` 顯示 + 「數值已過期」標籤;左緣 warning |
| 5 | 未選動作 | 阻斷 | 阻斷面板:「尚未選擇動作」+ 按鈕「選擇動作」(前往動作工作區) |
| 6 | 超限警報 | 警報 | 見 §8.3 |
| 7 | 警報已靜音 | 警報 | 同 6,邊框改虛線,靜音按鈕換成「靜音中 28s」倒數(不可再按) |
| 8 | 保持中 | 正向 | 保持環以 success 填滿、保持秒數 `numeric-l`;整圈 success 邊框 |
| 9 | 回位 | 中性 | 教練提示「完成!回到起始位」;次數 +1 時次數數字以 `motion-base` 做一次底色 success tint 淡出 |
| 10 | 進行中/待機 | 中性 | 量表 + 教練提示;在目標區時左緣 success |
| — | 未校準 | 疊加 | 不改變主面板狀態;命令列下方顯示 warning 橫條「尚未校準 · 啟動校準精靈」(沿用 `calib-chip` 行為) |
| — | 示範模式 | 疊加 | 全域橫幅(§7) |

**阻斷面板**是新元件:取代量表的位置,內容置中 = 32px 線條圖示 + `alert` 標題 + 一句 `body` 說明 +
至多一個主要按鈕。原則:**阻斷時不畫一個看起來在運作的量表**(延續 `MetricGauge` 對 `unsupported`
的既有考量,把它推廣到所有阻斷狀態)。

  三個分頁合併為單一分頁列(取代左右兩組 `LiquidKnob` 分頁),避免兩組選取指示器互相競爭注意力。

  字級無法保證;HTML 文字才能精確套用 `display` 104px。
- **量表配色**:底弧 `border`;目標帶 `success` 22%;進度弧在目標區外為 `text-dim`、目標區內
  `success`、超限 `danger`;超限刻線 `danger` 3px;回位刻線 `text-muted` 虛線。
  數值文字同規則。**不再用 accent 畫進度**(accent 不表示「做對」,§3.1)。

- 狀態邊框規則(§6.2)套用在整個工作區外框,讓警報在任何距離都能被看到。
- 專注模式為使用者層級設定,持久化;命令軌與命令列保留(不做全螢幕,避免與原生標題列行為衝突)。

### 8.3 超限警報

- 主面板:danger 12% tint 底 + 整圈 4px danger 1Hz 漸變邊框。
