# 膝過伸、警示門檻與提示措辭

統一校準產生帶符號膝角，負值代表過伸（genu recurvatum）。App 在 -5° 以下發出警示：`HYPEREXTENSION_TOLERANCE_DEG = 5`，位於 `feat/unified-calibration` commit `3c1c57d` 的 [movementMetric.ts](../../../IRMS_App_Tauri/src/services/movementMetric.ts)，不在本庫固定的 App 快照 `af65daa`。程式註解標為「待負責人審閱的提議值」，並寫明校準誤差預算約 2–4°；這個預算是註解中的估計，尚未經 V01／V02 實測。

本導讀回應 [缺口 G1／G2](../MAINTENANCE.md)。來源多為摘要層級，Guimarães 與 Nikolajsen 讀過指定全文章節；Beighton 原文未讀。標為「推論」的內容是本庫的工程或溝通判斷，沒有直接研究支持。

## 1. 過伸的定義與生理範圍

| 問題 | 已查核的內容 | 界限 |
|---|---|---|
| 定義 | 臨床綜述把 genu recurvatum 操作定義為伸直超過 5°。[Loudon 1998](../sources/PMID-9580896.md) | 敘述性綜述，沒有說明 5° 的實證來源 |
| 常見切點 | ACL 研究使用麻醉下對側膝的被動過伸 >5° 分組；作者在討論中指出文獻也用 6° 與 10°（Beighton）。[Guimarães 2021](../sources/PMID-34820464.md) | 被動、麻醉下的手術風險分組 |
| Beighton 膝項 | 一篇全文以「Beighton ≥6 且靜態站立膝過伸 ≥10°」作為納入條件。[Nikolajsen 2021](../sources/PMID-33573624.md) | [Beighton 原文](../sources/PMID-4751776.md) 未讀，原始條文未查核 |
| 正常伸直範圍 | 族群常模與教科書數值可差到 18°，而且 ROM 隨年齡與性別改變。[Roach 1991](../sources/PMID-1881956.md)、[Soucie 2011](../sources/PMID-21070485.md) | 兩篇都只讀摘要，**沒有取得膝伸直的具體常模數值** |
| 盛行率 | ACL 翻修族群中，被動過伸 ≥5° 佔 33%。[MARS 2018](../sources/PMID-29882693.md) | 高度選擇的手術族群，不能代表一般人 |
| 靜態與動態 | 靜態可過伸 ≥10° 的青少女，步行時膝角反而略偏屈曲。[Nikolajsen 2021](../sources/PMID-33573624.md) | 小樣本、無症狀、跑步機 |

**風險相關證據。** 術前被動過伸 ≥5° 與 ACL 翻修後移植物失敗有關（OR 2.12），也與初次膕旁肌腱重建的失敗率較高有關（14.7% 對 2.9%）。[MARS](../sources/PMID-29882693.md)、[Guimarães](../sources/PMID-34820464.md) TKA 術後結構性過伸 >5° 的部分生活品質分數較差，1–5° 則與 0° 相近。[Siddiqui 2012](../sources/PMID-22153947.md) 綜述提到過伸者可能出現膝痛與末端伸直控制不佳。[Loudon](../sources/PMID-9580896.md) 有研究把後關節囊、ACL 與前脛股關節應力增加當作背景說法，但沒有實際量測。[Teran-Yengle 2011](../sources/PMID-22030469.md) 本庫**沒有找到並查核**過伸與肌腱病變的直接研究。

**術後情境。** ACL 長期追蹤把「正常活動」定義為伸直（含過伸）與健側相差 2° 以內；失去 3–5° 伸直（含過伸）與較差結果相關。[Shelbourne 2009](../sources/PMID-19059893.md) 因此部分 ACL 方案以恢復與健側對稱的過伸為目標。Guimarães 也指出，以護具把術後過伸限制在 5° 以下能否改善結果，目前沒有資料完全支持。TKA 的過伸則是植入後的結構狀態，與運動中短暫的負角不同。中風後的過伸原因多樣，角度回饋在小型研究中可減少過伸。[Morris 1992](../sources/PMID-1463378.md)、[偏癱回顧](../sources/PMID-20153279.md)

**小結。** 5° 在文獻中反覆出現，但只用於靜態或被動量測的分組與定義。生理範圍因人、年齡、性別而異；本庫還沒有可引用的膝伸直常模數字。

## 2. IRMS 門檻如何建立

**文獻是否支持固定 5°？不支持。** 已查核的研究都沒有推導或驗證動態、穿戴式、即時的過伸警示門檻。5° 是靜態或被動情境的慣例，IRMS 最多只能把它當作暫定值，不能寫成「有文獻依據的安全界線」。[驗證計畫](../VALIDATION_PLAN.md) 也已規定，不能把其他系統的 5° 當作 IRMS 通過線。

**量測誤差的要求。** IRMS 的帶符號角是相對於校準零點的差值，誤差同時包含校準零點與當下讀值。即使是臨床量角器，伸直端的跨測者 ICC 也只有 .86。[Watkins 1991](../sources/PMID-1989012.md) 依 [統計導讀](04-validation-statistics.md)，門檻至少應高於 IRMS 自身的偏差與隨機誤差：

- `SEM = SD·sqrt(1−ICC)`；比較兩個讀值（例如校準零點與當下讀值）時，`MDC95 = 1.96·sqrt(2)·SEM`。[Weir 2005](../sources/PMID-15705040.md)
- 推論示例：如果總誤差的 SD 落在註解估計的 2–4°，真實角度為 0° 時，單一讀值的 95% 範圍約為 ±4–8°。在這種情況下，-5° 會在完全伸直的人身上產生誤報。這個數字只用來說明，實際 SD 仍需實測。
- 必要資料：V01 機械平臺的已知角要包含負角（例如 -10° 到 +10°）；V02 要測重戴與跨日 SEM。之後再用 `max(臨床設定值, |偏差| + z·SEM)` 決定最小可用門檻，並報告誤報與漏報率。

**工程建議（推論）。** 目前 `movementMetric.ts` 對單一樣本做 `knee < -5` 比較；`sessionController.ts` 另有狀態追蹤，但是否涵蓋過伸的停留時間與遲滯還需核對。建議：

1. 過伸警示加上最短停留時間與遲滯，避免在 0° 附近抖動時反覆觸發（V08）。
2. 門檻由治療師依族群設定，也可以關閉。ACL 術後若以健側對稱過伸為目標，固定 -5° 會與目標衝突；生理性過伸者可依個人基準設定。
3. 記錄觸發事件、當下角度、校準版本與門檻設定，供 V08／V12 分析。

## 3. 警示措辭

**目前的語句：** `膝蓋過度伸直 {deg}°,請放鬆,不要向後頂`（語音 `膝蓋過度伸直,請放鬆`）。下表的原則用來檢查這句話。沒有研究直接比較膝過伸的警示語句，也沒有中文提示語研究，因此每條原則都標明證據層級。

| 原則 | 依據 | 證據層級 |
|---|---|---|
| 說出要做的動作，少用「不要」 | 負向指示會讓結果往反方向過度補償。[de la Peña 2008](../sources/PMID-18819030.md) 描述動作效果、建立正向預期較有利於學習。[OPTIMAL](../sources/PMID-26833314.md)、[Benjaminse 2015](../sources/PMID-25627151.md) | 健康人推桿實驗與理論回顧外推 |
| 不怪罪，不暗示受傷或危險 | 臨床人員的說法會長期影響信念；「需要保護」的訊息可能帶來警戒與罪惡感。[Darlow 2013](../sources/PMID-24218376.md)、[Stewart 2018](../sources/PMID-30067920.md)、[nocebo 回顧](../sources/PMID-27133031.md) | 下背痛質性研究、觀點與回顧外推 |
| 語音要短，一次只講一個動作 | 聽覺回饋的設計準則。[Sigrist 2013](../sources/PMID-23132605.md) | 回顧，非語句研究 |
| 語音不念度數；文字顯示時用「約」 | 0° 附近的數度差可能落在量測誤差內（第 2 節） | 推論 |
| 避免「放鬆」 | 「放鬆」可能被理解成讓膝蓋鬆開往後靠 | 推論，未經驗證 |
| 說「超過設定的範圍」，不說「異常」 | 生理性過伸者與 ACL 術後需要對稱過伸的人，都不應被當成錯誤。[Nikolajsen](../sources/PMID-33573624.md)、[Shelbourne](../sources/PMID-19059893.md) | 推論 |
| 中英文分別寫成自然語句，不逐字翻譯 | 雙語提示要各自通順 | 推論 |

**候選語句（依預設適用性排序，全部屬專家推論，需經 V11 測試）**

| 排名 | 中文文字／語音 | English text / voice | 理由 |
|---|---|---|---|
| 1 | `膝蓋稍微彎一點`；次行 `已超過設定的伸直範圍（約 {deg}°）`／語音 `膝蓋稍微彎一點` | `Keep a slight bend in your knee`; sub-line `Past your set straightening limit (about {deg}°)` / `Slight knee bend` | 正向且可執行，不責怪；語音短；度數只在文字中、標為約略值；以「設定範圍」描述，不把生理性過伸當成異常 |
| 2 | `伸直到這裡就好，膝蓋留一點彎度`／語音 `留一點彎度` | `That's straight enough. Keep a little bend` / `Keep a little bend` | 先肯定伸直，適合 TKA／ACL 術後「要完全伸直，但不要過伸」；文字較長，語音版再縮短 |
| 3 | `膝蓋往後伸多了，稍微彎回來就好`／語音 `稍微彎回來` | `Knee is past straight. Ease into a slight bend` / `Ease into a slight bend` | 說明發生什麼並給出修正；「多了」帶輕微評價，「就好」降低壓力 |
| 不建議 | 現行語句；含「危險、受傷、錯誤、鎖死、反弓、不要向後頂」的語句 | `hyperextended`, `danger`, `do not push back`, `locked` | 負向指示、診斷式標籤、精確度數造成的誤導，以及「放鬆」的歧義 |

**測試方式（V11）。** 讓目標使用者（含年長者、TKA／ACL 術後、生理性過伸者）聽語音或看文字後做出動作，記錄是否做對（微彎而不是深屈）、反應時間、焦慮與信任評分，中英文分開；同時確認 TTS 的發音是否清楚。測試前不要把任何候選句寫成「已驗證」。
