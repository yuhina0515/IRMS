# 使用性、研究設計與部署

裝置的技術成功與使用者能否完成流程是不同終點。應以任務觀察測量佩戴、校準、開始、理解回饋、結束與回看；單純詢問「好不好用」不足以發現錯誤與使用障礙。患者與治療師的需求也可能不同。[原型使用者評估](../sources/PMID-30669657.md)、[治療師訪談](../sources/PMID-30366919.md)

| 階段 | 建議觀察 |
|---|---|
| 首次使用 | 正確佩戴、校準完成率與幫助次數 |
| 動作當下 | 是否理解計次／超限／斷線提示 |
| 日常使用 | 重戴、放置、連線與程序負擔 |
| 回看紀錄 | 是否能解讀缺失與量測限制 |
| 專業工作 | 是否可追溯設定、任務與研究版本 |

無障礙可從鍵盤、焦點、可感知狀態與文字替代檢查。顏色與聲音應避免成為唯一資訊來源；這些通用可及性條件仍需與目標族群的動作、視力、認知與語言需求一起驗證。[WCAG 2.2](../sources/DOC-WCAG22.md)

研究建議按問題循序推進：先做訊號與角度技術驗證，再做佩戴與程序可行性，最後才評估特定服務模式的介入結果。先導研究應有招募、資料完整與程序進展標準，不能用小樣本滿意度就判定療效。[先導報告延伸](../sources/PMID-27965879.md)

正式隨機試驗可依 SPIRIT 2025 建立計畫書，依 CONSORT 2025 報告。先定義主要終點、比較組、介入劑量、監督、缺失規則、樣本數依據與分析方式。兩個清單支持透明報告，不會代替設計品質或研究審查。2010 文獻保留作歷史與延伸背景，不能當成目前唯一版本。[SPIRIT 2025](../sources/PMID-40294593.md)、[CONSORT 2025](../sources/PMID-40228499.md)

非劣性／等效需要事先合理的邊界與對應分析，`p>0.05` 不是等效證據。患者回報量表可參考 COSMIN，但某些清單專為 PROM，不能不加說明地當成 IMU 硬體品質評分。[非劣性報告](../sources/PMID-23268518.md)、[COSMIN 適用範圍](../sources/PMID-29260445.md)

FDA 遠距研究資料指引提供適用用途、技術驗證與資料可用性背景，原適用情境為臨床研究資料採集。它不證明 IRMS 已獲批準，也不裁決臺灣或其他地區法規。[FDA DHT](../sources/DOC-FDA-DHT.md)

建議最後報告包含實際使用錯誤、無效資料比例、退出／拒用原因、技術故障與族群限制。現有 App 測試、模擬模式與瀏覽器預覽應與真機、人體及研究驗證分開列出。
