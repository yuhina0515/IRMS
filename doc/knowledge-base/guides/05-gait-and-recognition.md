# 步態、運動辨識與計次

步態事件、運動名稱、次數與動作品質是四種不同任務。足跟初始接觸或離地需要對應的參考標記；知道「正在蹲」不能保證知道每一下是否符合定義，更不能推論全部代償都被檢出。

步態文獻常使用足部、小腿或下背原始加速度及角速度。IRMS 目前的肢段角與正規化向量，不等同這些研究的輸入。新增步態模組前，應列出需要的感測位置、訊號、採樣率及參考事件；不能只因同樣有兩顆 IMU 就移植全部指標。[事件回顧](../sources/PMID-33924403.md)、[步態分期](../sources/PMID-26751449.md)

25 Hz 串流的單一樣本間隔是 40 ms。以樣本邊界直接標記事件會受這個離散程度限制；插值能改變估計方法，不能自動補回未量到的高頻內容。感測器本身採集較快，也不代表 App 已接收到全部原始樣本。延遲、抖動與裝置／主機時間差需另測。

| 任務 | 標籤需求 | 建議報告 |
|---|---|---|
| 活動／運動辨識 | 包括非運動與未知類 | 各類 precision、recall、F1 與混淆矩陣 |
| 重複次數 | 每一下開始、完成與中止 | 每場計次誤差、誤計／漏計 |
| 步態事件 | 獨立的接觸／離地參考 | 時間誤差分布、漏檢與誤檢 |
| 品質評估 | 專業評分規則與評分者一致性 | 與參考評分的誤差、一致性及未知情境 |

同一受試者或同一連續試次切出的重疊視窗，若分散到訓練與測試集，可能導致洩漏。按受試者與試次先切分，再建立視窗；特徵標準化、選擇與調參都只能使用訓練部分。新受試者泛化與患者特定模型應分開報告。這是 IRMS 的建議研究設計，不是現有模型已達到的能力。[跨受試者案例](../sources/PMID-26805847.md)

真實居家環境包含走到椅子、坐下、整理綁帶及休息。訓練資料不能只有「標準且正在做運動」的片段；研究顯示納入非運動片段對偵測有價值。慢速、短步行段及病理步態也可能降低演算法表現。[居家辨識](../sources/PMID-37051835.md)、[真實生活步態](../sources/PMID-37316858.md)

可先用 [GAITEX](../sources/PMID-41469404.md) 的同步與品質標記測試方法，或以 [肌耐力辨識／計次研究](../sources/PMID-32854288.md) 比較評估策略，再以 IRMS 自有資料驗證。資料集得分不能替代實際佩戴、協定與族群的驗證。
