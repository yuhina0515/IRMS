# 復健背景、功能終點與遠距服務

IRMS 的研究背景可連到穿戴式量測、居家練習與功能追蹤，但應先定義使用情境：教育展示、記錄動作、研究資料採集或臨床服務，是不同用途。WHO 的 ICF 提醒身體功能、活動與參與分屬不同層次；膝角只能描述其中一部分。[ICF](../sources/DOC-WHO-ICF.md)、[復健需求背景](../sources/DOC-WHO-REHAB.md)

| 終點層次 | 示例 | 不能推論的事情 |
|---|---|---|
| 技術量測 | 角度誤差、資料完整性 | 疼痛或生活功能改善 |
| 動作表現 | ROM、次數、維持時間 | 組織負荷或動作全面安全 |
| 功能活動 | 坐站、步行、階梯任務 | 只由膝角即可描述代償 |
| 患者經驗 | 疼痛、困難、信心、滿意度 | 自動等同客觀活動量 |
| 服務結果 | 依從性、資源、長期追蹤 | 可移植到任意居家產品 |

骨關節炎與關節置換指引提供個人化管理及照護背景；不是給所有人的固定復健角度表。本知識庫不提供患者處方，也不把 App 預設目標當作臨床建議。實際試驗應由相應專業人員定義適用族群、任務與照護安排。[NICE 骨關節炎](../sources/DOC-NICE-OA.md)、[NICE 關節置換](../sources/DOC-NICE-JOINT.md)

膝置換的遠距研究包括即時視訊、非同步服務及帶臨床監督的虛擬復健。裝置、運動內容、訓練頻率、監督與追蹤共同形成介入，不能把整套服務效果歸因於 IMU。不同結果也不完全一致，部分統計改善未達臨床重要幅度。[非劣性試驗](../sources/PMID-26178888.md)、[VERITAS](../sources/PMID-31743238.md)、[技術輔助統合分析](../sources/PMID-31679511.md)

將 ROM、患者回報與多任務表現並列，比單一「進步百分比」更容易保持解讀邊界。膝置換研究顯示患者回報與慣性功能指標可互補；自由生活骨關節炎回顧也指出感測資料與主觀癥狀整合不足。[互補量測](../sources/PMID-26032657.md)、[自由生活癥狀](../sources/PMID-42391637.md)

IRMS 的舒適與極限紀錄應描述為個人設定或測試紀錄，不能宣稱為診斷、術後承重允許量或受傷風險量表。內收力矩與接觸力研究使用額外模型與訊號，膝角本身不能直接提供這些負荷。[力矩估計](../sources/PMID-32039192.md)、[接觸力模型](../sources/PMID-30970538.md)

程式對照：[歷程分析](../../../IRMS_App_Tauri/src/services/sessionAnalysis.ts)。研究計畫應事先決定哪些終點是主要的、哪些是探索性的，避免看到改善後才挑選指標。
