# 訊號、姿態融合與延遲

應將採集、韌體融合、BLE、校準、App 平滑、判定與顯示視為連續資料鏈。某一層訊號變平滑，不代表整體角度更準；平滑可能降低抖動，同時讓進區、維持與警報判斷變晚。

本次檢查獨立韌體倉庫 `config.h/imu.h`：感測週期 20 ms、傳輸週期 40 ms、互補濾波陀螺積分權重 0.85，且有積分 dt 上限。這些是程式設定，不是實測採樣穩定性。App `smoothing.ts` 的新樣本權重是 0.3；基礎角度沿最短弧平滑，膝角作為自身指標平滑，Roll 差另行重算。

互補濾波的一般形式為 `angle_k = a(angle_(k−1) + gyro_k·dt) + (1−a)acc_angle_k`。陀螺儀積分受偏移影響；加速度傾角受動態分量影響。兩個二維 atan2 傾角也不是任意三維姿態的完整表示。轉彎、快速屈伸、振動與長時間靜止應分開比較。[姿態處理回顧](../sources/PMID-22319365.md)、[動態傾角方法](../sources/PMID-25775483.md)

對固定間隔的 EMA，`y_k=(1−b)y_(k−1)+b x_k`。以本次程式設定 `b=0.3`、`T=0.04 s` 計算，離散極點對應的時間常數為 `−T/ln(1−b)≈0.112 s`，低頻群延遲近似 `(1−b)T/b≈0.093 s`。這是濾波數學估計，沒有包含韌體、無線、排程、裝置回饋等延遲，也不是實測或文獻給出的臨床容許值。

| 比較項目 | 必須控制的條件 |
|---|---|
| 靜態偏移／漂移 | 暖機、時間、溫度、姿勢 |
| 動態誤差 | 動作幅度、速度、線性加速度 |
| 收斂與重置 | 開機、校準、斷線與恢復 |
| 回饋延遲 | 共同時間基準與完整事件鏈 |
| 演算法候選 | 同一原始資料、參數與因果模式 |

Madgwick 報告與 VQF 可作為候選演算法導讀，不能直接套用作者性能數字。VQF 的線上與離線版本尤其需分開；使用未來資料的離線結果不能代表即時回饋。比較文獻也顯示硬體與運動速率會改變演算法表現。[Madgwick](../sources/ALG-MADGWICK2010.md)、[VQF](../sources/ALG-VQF2023.md)、[多演算法比較](../sources/PMID-33916432.md)
