# 量測模型：從感測器到膝關節角

IRMS 的專業論述應先定義「量到什麼」。加速度計量測包含重力影響與運動分量的比力，陀螺儀量測角速度；兩者都在感測器自己的座標系。感測器 Pitch、肢段傾斜、兩向量夾角、鉸鏈屈伸及解剖三維膝角，是不同量。

| 層次 | 必須定義 | 常見誤解 |
|---|---|---|
| 原始訊號 | 軸向、單位、量程、時間戳 | 正規化向量仍保存完整加速度大小 |
| 感測器姿態 | 參考系、表示法、估計方法 | 六軸可以在所有條件下取得絕對航向 |
| 肢段姿態 | 感測器到肢段的固定轉換 | 綁在腿上就與解剖軸對齊 |
| 關節相對運動 | 近遠端座標與關節模型 | 任意兩個局部座標向量可直接內積 |
| 臨床解讀 | 族群、動作、功能及誤差 | ROM 變大就代表完整復原 |

若兩肢段姿態都相對同一世界座標表示，可用 `R_relative = R_proximal^T R_distal` 建立相對旋轉；選定關節座標系後再分解角度。感測器到肢段轉換必須先納入。純向量夾角 `acos(clamp(u·v/(|u||v|), -1, 1))` 也要求 `u` 與 `v` 在同一座標系，不能只因兩向量都正規化就認定可比較。這些式子是幾何定義，並非 IRMS 已完成的準確度驗證。

本次對照 `useStore.ts/applyCalibration`：兩側具備加速度向量、零位向量及鉸鏈軸時，走鉸鏈投影後的肢段角最短弧差；缺少完整鉸鏈設定但有兩側向量時，仍有「向量夾角扣站姿差」的相容路徑；舊封包另有角度重建路徑。三種路徑應分層驗證。`kneeRoll` 是校準後 Roll 的帶符號最短弧差，尚不能僅憑名稱宣稱為臨床內外翻量測。

膝在人體並非完美單軸鉸鏈。六軸無磁力計可以在適當運動限制與充分激發下估計某些相對運動，仍有可觀測性、奇異姿態與模型偏差；3D 畫面呈現不是六自由度量測的證明。應以「本專案實作的屈伸／投影指標」描述未完成驗證的輸出。
