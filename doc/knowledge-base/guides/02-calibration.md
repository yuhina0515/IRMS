# 佩戴、校準與品質判斷

校準至少包含感測器本身的偏移／尺度、感測器到肢段的對齊，以及關節零位。這三件事不應只用一個「校準完成」指示混在一起。站姿歸零不會自動消除軸向誤差，功能軸辨識也不會消除綁帶滑動。

校準回顧將程序分為手動、靜態、功能及解剖四類。靜態方法依賴已知姿勢與重力；功能方法從指定或自然運動辨識軸；解剖方法依賴骨性標記或外部參照；手動方法依賴對齊操作。不同關節與任務的結果有取捨，不能宣稱任一種永遠最佳。[校準回顧](../sources/PMID-32545227.md)、[下肢校準比較](../sources/PMID-32012906.md)

IRMS 目前由兩次靜止向量等資訊建立功能方向與鉸鏈框架，並有方向、零位及舊設定相容處理。這不同於文獻以持續三軸角速度與關節限制進行的即插即用軸估計。新增演算法前，先確認所需原始訊號是否能取得；「同樣使用功能動作」不足以證明演算法等價。[關節軸估計](../sources/PMID-32580394.md)

| 檢查層次 | 候選品質資訊 | 失敗時應記錄 |
|---|---|---|
| 靜止片段 | 圓形角度離散、重力方向一致性 | 樣本數、原始值與擷取時間 |
| 動作激發 | 基準與移動向量分離程度 | 動作幅度不足或近退化幾何 |
| 軸辨識 | 外積大小、重複軸差異 | 軸不穩定或設定缺漏 |
| 佩戴穩定 | 跨次站姿／標準動作差異 | 綁帶滑動、衣物與位置 |
| 程序再現 | 重戴、操作者及日期 | 哪一層造成變動 |

表中是待評估的工程指標，沒有指定通用通過閾值，也沒有宣稱所有指標已在 IRMS 實作。應先用已知軸平臺及試驗資料估計失敗分佈，再決定產品程序。

角度跨越 ±180° 時，平均與差值需使用環形運算。例如 179° 與 −179° 的平均應接近 180°，最短差為 2°。IRMS 的 `angleMath.ts` 已提供相關處理；校準驗證要覆蓋分支切點、反相及歷史設定遷移。圓形處理避免數值錯誤，不會自動改善解剖對齊。

重戴測試應保留「同一次校準內重測」與「拆下重戴後重新校準」兩組；前者較偏向訊號與程序，後者才反映佩戴及操作者影響。功能校準降低部分位置差異，但軟組織影響仍存在。[近期位置研究](../sources/PMID-41569824.md)、[單姿勢重現性](../sources/PMID-28279850.md)
