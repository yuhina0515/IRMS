# 量測驗證與統計解讀

先定義估計量、適用動作與可接受誤差，再選統計方法。系統間高度相關只能說波形一起變動；固定加上十度仍可能高度相關。準確度、重複性、波形形狀及可偵測變化應分開報告。[Bland–Altman 導讀](../sources/PMID-26110027.md)

| 問題 | 指標 | 解讀限制 |
|---|---|---|
| 誤差多大 | MAE、RMSE、誤差分位數 | 指定角度、時間點與單位 |
| 有無偏移 | 平均差、Bland–Altman 圖 | 需檢查異質變異與重複量測 |
| 波形相似嗎 | 相關、中心化 RMSE | 去均值會隱藏零位偏差 |
| 重測可靠嗎 | ICC 與信賴區間 | 模型與評分形式影響結果 |
| 個人改變超過誤差嗎 | SEM、MDC | 超過量測誤差不等同臨床重要 |
| 運動功能有改善嗎 | 功能終點與患者回報 | 需要介入研究與適當比較組 |

獨立且近似常態差值的基本 Bland–Altman 一致性界限為 `mean(d) ± 1.96·SD(d)`；不能把同一受試者數千個自相關時間點當成數千個獨立樣本。人體研究應以受試者層級、重複量測方法或合適的階層模型計算不確定性。可接受界限需事先按用途定義，不能觀察結果後才選。

ICC 應記錄單／雙向模型、單次／平均量測以及一致程度／絕對一致性。使用固定操作者與推廣到任意操作者是不同問題；單次量測性能不能用多次平均的 ICC 代替。[ICC 選擇](../sources/PMID-27330520.md)

在相應的經典信度模型與假設下，常見 `SEM=SD·sqrt(1−ICC)`、`MDC95=1.96·sqrt(2)·SEM`。SD 來源、ICC 形式與誤差結構必須相符；這些值需由 IRMS 目標試驗取得，不能套用其他感測器數字。MDC 是可偵測改變，MCID／MIC 是重要改變，兩者概念不同。[重測與 SEM](../sources/PMID-15705040.md)

光學參考也有座標、標記與軟組織誤差。標記直接貼在 IMU 外殼時較偏向感測器姿態對照；以解剖標記估計肢段時包含附著與建模誤差。兩種驗證應清楚區分。[轉臺驗證](../sources/PMID-21715167.md)、[軟組織影響](../sources/PMID-16022983.md)

報告模板：受試者數／試次數、裝置與版本、佩戴與校準、參考模型、對齊方法、缺失處理、主要終點、事前允許誤差、分層結果與信賴區間。不要只報整體平均或最佳一次測試。具體待驗證工作見 [驗證計畫](../VALIDATION_PLAN.md)。
