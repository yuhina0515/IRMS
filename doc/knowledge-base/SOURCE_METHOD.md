# 來源方法、篩選與證據深度

這是主題導向的人工選編參考庫，服務 IRMS 的工程與研究問題。不是 PRISMA 系統性回顧，沒有宣稱搜尋窮盡、雙人獨立篩選或已完成統合分析。PRISMA 本身是報告指引，也不能替代完整方法。[PRISMA 2020](sources/PMID-33789826.md)

## 取得方式

以 Europe PMC REST API 的 `resultType=core` 取得 MED／PubMed 來源書目及摘要。13 個研究主題分兩批：一批截止 2024-12-31 並按被引排序以發現經典來源；另一批截止 2026-10-03 發現近期材料。被引排序只幫助發現文獻，不作為品質或療效等級。另檢索 CONSORT／SPIRIT 2025，兩個框架各選一份 JAMA 原始版本，避免把同時刊於多期刊的同一指引當成多項獨立證據。

研究主題包括下肢運動學、肢段校準、關節軸／無磁力計、姿態融合、固定偽影、步態、回饋、遠距療程、膝部背景、辨識／品質、使用性、量測統計及座標系。各來源保留查詢或記錄入口；完整候選查詢與結果數見 [query-manifest.json](data/query-manifest.json)。候選原始摘要只留在本次暫存區，沒有打包出版商全文或全文摘要集合。

VQF 的 DOI 書目另經 Crossref 核對，摘要經作者所屬機構頁面確認。Madgwick 使用作者公開的 2010 技術報告，清楚區別期刊文章與技術報告。官方文件選取原廠、規格組織、專案作者、WHO、NICE、FDA、NIST、W3C 與 UCI 的原始入口。

## 篩選原則

納入：能支援明確的 IRMS 問題、具有可追溯書目或官方身分、研究在日期截止前首次公開。包括方法、驗證、回顧、介入、質性研究與資料描述，保留其不同證據用途。僅在概念或模組擴充有用時納入上肢、神經疾病等外部情境，來源卡明示外推限制。

排除：與人體運動無關的基因／動物／材料檢索噪音、缺乏出處的部落格、明確勘誤／撤稿類型、未取得摘要而需推測結果的研究，以及與問題無關的多模態成果。書目按 PMID／DOI 去重；相同來源可跨主題索引，不能重複算入總數。API 篩選不是完整撤稿調查；重要引用在使用時需再查期刊更正、撤稿與版本狀態。

## 內容整理與界限

摘要導讀只整理研究目的、方法方向或摘要主要限制；沒有全面提取樣本數、效果量、誤差、偏誤風險或詳盡設定。因此一般來源的 `study_type` 只是依標題／PubMed 類型作的描述分類，未知設計明記為未擷取，不冒充完整研究評讀。

`priority=core` 代表優先閱讀價值，不是證據品質評分。回顧數量、被引次數、期刊名稱或 open-access 旗標都不當作療效等級。導讀中的數學推導與工程建議會與文獻結論分開。來源的族群、裝置與演算法不同，不能借其數值證明 IRMS。

兩份 TDK 原始 PDF 的身分由官方目錄確認，但本次直接存取被阻擋／轉址，因此僅標示 metadata-only，不能用作已核對的數值依據。連結查核亦檢查 PDF 是否真的回傳 PDF，避免以一般搜尋頁的 200 狀態冒充成功。

## 後續升級為正式文獻評讀

先固定研究問題與納入條件，擴充所需資料庫與完整搜尋，再逐篇全文擷取研究族群、設備、參考系、校準、運動、樣本、誤差、時序及偏誤。建立原始研究與回顧的依賴關係，依適用方法評估品質，最後才評估是否能統合。這些步驟目前尚未完成。
