## 每次必須保存的資料包

| 欄位／檔案 | 必須記錄 | 缺失的後果 |
|---|---|---|
| manifest | 試驗 ID、日期、App／韌體版本與 commit、裝置型號／去識別 ID、操作者、輸出定義、判定路徑 | 不能宣稱其他版本或路徑的性能。 |
| calibration | 該次完整 JSON、雙端 zeroAccel／hingeAxis、反轉與相容設定；校準成功／拒絕原因 | 不能用目前設定代替舊試次設定。 |
| device data | 帶時間戳的原始可取得封包及 App 全量輸出，標記 device／demo、缺口、重連、截斷、錯誤 | demo 不作真機證據；只存曲線圖片不能重現。 |
| reference data | 參考角度、單位、時間、來源／版本、解析度、校準與不確定性、是否獨立 | 解析度不是準確度；觀察「約90°」不能代替已知角。 |
| trial labels | 任務、開始／停止、靜止／移動、姿勢／速度條件、衣物／綁帶／位置、戴卸／操作者順序 | 無標記不能由波形猜原任務。 |
| analysis | 時間對齊、濾波、是否去均值、排除理由、程式版本、所有試次與失敗 | 只報最佳試次或校正後誤差會隱藏問題。 |

目前公開封包是角度與正規化加速度向量，不是完整三軸加速度／陀螺原始資料。未取得這些訊號前，不承諾重跑所有姿態融合方法。Session 資料庫的校準快照與原始封包是不同資產，均需保存並核對。

## V01：獨立已知角

1. 先確認裝置及剛性兩段平臺可用；建立獨立參考及其不確定性。依預定量測範圍安排端點、中間角、正反移動方向、純軸與混合運動。角度與允許誤差在看結果之前固定，不照搬文獻 3°／5°。
2. 相同實體試次保留完整鉸鏈、向量相容與舊角度路徑的明確設定，各自呈現。校準／固定未變更時的重複，與重新戴裝後的重複分開。
3. 同步記錄裝置、App 與參考；靜止角檢查不能代替動態延遲。記錄共同事件與每次對齊方法；若用參考曲線互相關，另報未修正相位差。
4. 每條路徑／角度／方向至少能辨認獨立試次，報偏差、MAE、RMSE、最大誤差、原始點數、有效時間、缺口與參考不確定性。計算不確定性時以實際試次單位處理，不能用串流點數當樣本量。
5. 只有觀察範圍內數據支持預先界限時才標通過；保存不通過與不能判定的條件。

設計依據：[CMM 已知角](reviews/PMID-28846613.md)、[機械軸辨識](reviews/PMID-32580394.md)。臺架未含皮膚／軟組織，因此也不能證明人體角度準確度。

## V02：校準、戴卸、操作者與日期

1. 分開四種情境：同次穿戴重跑校準、拆下重戴、另一操作者戴裝、跨日重測。三次校準擷取的既有檢查可沿用 [CAL-02 歷史設計](../coding%20log/log_20260917_cal02_design_decision.md)，但不把三次當已足夠估計所有信度。
2. 每次保存完整設定與戴裝條件；記錄操作者與順序、休息及環境，不在不同試次間偷偷保留前次軸或零位。參考的戴卸與標記位置若未重設，明寫比較範圍。
3. 固定估計量與動作；失敗校準、故障／電量／同步、未回診與排除均留分母及理由。操作者／日期的效果與人體動作變異分開。
4. 事前指定 ICC 的模型、單次／平均及絕對一致性／一致程度；對固定操作者的結論不自動推廣到任意操作者。樣本計畫依目標信賴區間與先導變異，不由封包數或任意人數取代。
5. 報平均偏移、誤差、校準失敗率、ICC 與區間；SEM／MDC 需與 SD／ICC／誤差模型匹配，不能把 MDC 或 1 SEM 等同患者重要變化。

設計依據：[真實戴卸與兩操作者](reviews/PMID-29495600.md)、[患者跨日／操作者](reviews/PMID-41901917.md)、[ICC 更正](EVIDENCE_RECONCILIATION.md)。

## V05：人體參考研究的預先規劃

先在 V01／V02 完成後，根據剩餘誤差決定哪些人體問題值得研究，而非先認定「已準確」。規劃須包含：

- **目的與族群**：先限定估計量、動作及使用情境；健康可行性與患者效度分開。年齡、癥狀／病變、輔具及活動限制事先定義。
- **參考層級**：同步光學或其他可證明性能的參考；外殼剛性標記與解剖標記分開，記錄參考模型及標記者、旋轉序列、軟組織誤差與共同時間事件。
- **主要終點**：絕對角偏差／RMSE與信賴區間；ROM、中心化波形、不同平面及延遲作明確次要終點。不得為得到較小誤差而事後換終點。
- **樣本與分析**：以受試者為獨立單位，利用先導變異與目標精度規劃數量；同一人的兩側／多試次採合適重複量測或階層方法。明列失敗、缺失與不同校準路徑。
- **研究程序**：先確定適用的倫理／同意／去識別及資料管理程序，再收人體資料；這份文件未招募、未執行人體試驗。若日後評介入效果，另需匹配訓練量、對照與保留／轉移終點。

依據：[方法性回顧](reviews/PMID-31991862.md)、[病變步態效度](reviews/PMID-41901917.md)、[SPIRIT](sources/PMID-40294593.md)、[CONSORT](sources/PMID-40228499.md)。
