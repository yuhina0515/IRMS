# Inertial Sensor-Based Robust Gait Analysis in Non-Hospital Settings for Neurological Disorders.

來源：[PMID-28398224](../sources/PMID-28398224.md)；摘錄日：2026-10-06。

[原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5422186/) · [原始 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC5422186/fullTextXML)

## 核心判讀

足部IMU對Kinect／慢動作攝影的初步驗證，可支持院外步態方法；不是膝角、診斷準確率或介入效果驗證。

## 研究事實與定位

| 欄位 | 摘錄 | 原文位置 |
|---|---|---|
| 研究設計 | 兩階段：22人參考比較，另17位神經疾病患者病例展示；16健康控制來自第一階段，不是新增獨立控制樣本。 | §6、§6.1–6.2 |
| 族群與樣本 | 22人驗證含16健康（8男／8女）與6神經疾病（3男／3女）；疾病包含失智、MCI、NPH與PD，病例組17人另列。 | §6.1–6.2、Tables 3–4 |
| 設備與取樣 | 兩足EXEL ExLs3、100Hz、±4g與1000°/s範圍，Velcro口袋固定；參考Kinect v2及240fps慢動作攝影。 | §4.1、§6.1 |
| 實驗程序 | 能自行穿戴則自行戴以增加位置差異；首選速度走直線及轉向，各人3–5場，Kinect比較只用1.5–4m有效區。 | §4.2、§6.1 |
| 參考系統 | 步幅對Kinect、擺動時間對逐影格IC／FO標註；作者明說Kinect不是gold-standard真值，結論承認需更強參考。 | §6.1、§7 |
| 分析方法 | error-state Kalman／零速修正、RTS平滑、粒子濾波與足部軸／事件檢測；每步末方向向後傳播，非完全因果即時分析。 | §5.1–5.6 |

## 結果

- 步幅RMSE0.05m、r²=0.98；擺動時間RMSE0.02s、r²=0.95，均為該22人與參考條件。（§6.1、Figures 14–15）
- 另17人資料展示與臨床觀察對照，沒有診斷敏感度／特異度或療效對照試驗。（§6.2、§7）

## 限制與閱讀評析

- 初步比較欠gold-standard、病例展示而非系統診斷驗證；需更多患者與臨床內容研究。（§7；author）
- 足部固定、原始加速度／陀螺與後向平滑不同於IRMS大腿／小腿正規化向量封包。（§4–5；reviewer-inference）

院外方法的可部署性與參考效度須分開。病例視覺化能展示需求，但不能據少量展示推成病人診斷或用藥決策能力。

本篇尚未進行逐項品質評讀；全文摘錄不是正式偏誤評分。

## IRMS 工程推論

以下是專案推論，不是原文直接驗證 IRMS 的結果。

- C14／V05 若研究步態，先明定足部或肢段位置、參考事件與輸入；不能把膝角直接當足部步幅。
- V06 標註RTS與步末回傳造成的非因果處理；V07時序另測，不引用該RMSE作即時延遲。
