# Method for Estimating Three-Dimensional Knee Rotations Using Two Inertial Measurement Units: Validation with a Coordinate Measurement Machine.

來源：[PMID-28846613](../sources/PMID-28846613.md)；摘錄日：2026-10-06。

[原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5620966/) · [原始 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC5620966/fullTextXML)

## 核心判讀

已知角機械基準可辨別共同座標與漂移問題；臺架RMS誤差不能代替人體STA或三維膝角效度。

## 研究事實與定位

| 欄位 | 摘錄 | 原文位置 |
|---|---|---|
| 研究設計 | MicroScribe G2X坐標量測機作膝類比，三旋轉軸可鎖；兩顆IMU剛性固定，對編碼器獨立參考。 | §2 |
| 族群與樣本 | 沒有人體樣本；四類機械動作（純屈伸／內外旋／內外展／混合）各50試次，單次約10秒。 | §2.1 |
| 設備與取樣 | 兩顆APDM Opal與CMM；作者報編碼器0.0003°解析度，非整機絕對角準確度。本文主文未明確列採樣率。 | §2 |
| 實驗程序 | 鎖軸轉底座以角速度同步；各肢段靜止垂直約10秒，再鎖其他軸做純屈伸校準；手動產生各類試次。 | §2.1 |
| 參考系統 | 三軸光學編碼器角度；機械軸串列需與ISB相反的分解次序，不能直接當人體同名角度。 | §2、§2.3 |
| 分析方法 | 使用廠商姿態四元數與磁北各自世界框架，鉸鏈條件修正共同框架；非鉸鏈期間在前後更新時點間線性內插。 | §2.2–2.3 |

## 結果

- 純屈伸RMS誤差3.90°；混合3D屈伸3.46°、內外旋2.48°、內外展1.69°。數字為RMS，不是每點最大誤差。（Tables 1–2、§3）

## 限制與閱讀評析

- 人體膝鬆弛、皮膚／軟組織附著及校準動作需另研究，機械判定門檻需調整。（§3末段；author）
- 使用後續鉸鏈更新時點的內插屬批次或需緩衝，不能直接稱逐封包因果處理。（§2.3 Not Functioning as a Hinge；reviewer-inference）

明確提供已知角參考設計；解析度、參考不確定性、RMS與峰值各不同。僅以完整向量與角度的IRMS公開封包不能重跑廠商四元數輸入。

本篇尚未進行逐項品質評讀；全文摘錄不是正式偏誤評分。

## IRMS 工程推論

以下是專案推論，不是原文直接驗證 IRMS 的結果。

- V01 必須用獨立已知角與剛性固定，分別報RMS、最大誤差、參考不確定性，不能以目視90°代替。
- C05／V04 對照磁力計、共同框架、分解順序與鉸鏈條件，不借臺架結果宣稱kneeRoll已具臨床效度。
