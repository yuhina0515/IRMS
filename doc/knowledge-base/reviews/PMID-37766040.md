# Inertial Measurement Unit Sensor-to-Segment Calibration Comparison for Sport-Specific Motion Analysis.

來源：[PMID-37766040](../sources/PMID-37766040.md)；摘錄日：2026-10-06。

[原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10534374/) · [原始 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC10534374/fullTextXML)

## 核心判讀

11位健康者的校準比較顯示任務與平面差異；首尾姿勢扣漂移與挑代表試次不等於即時全試次性能。

## 研究事實與定位

| 欄位 | 摘錄 | 原文位置 |
|---|---|---|
| 研究設計 | 便利樣本單次實驗，兩靜態姿勢／六功能校準，步行加七種運動任務。 | §2.1–2.3 |
| 族群與樣本 | 11位健康志願者，4女，24.5±3.5歲；排除妨礙任務的骨科問題或近六個月傷害。 | §2.1 |
| 設備與取樣 | 7顆Delsys Trigno Avanti，240 Hz、±16g／±2000°/s；14相機Vicon 240 Hz，以trigger同步，解剖標記。 | §2.2 |
| 實驗程序 | 各校準兩次、各任務兩次，錯誤可加做；按最低蹲深／最遠跳／最高跳／最快入場選一代表試次。 | §2.3 |
| 參考系統 | modified Cleveland Clinic解剖標記及自訂6-DOF光學模型；不是直接外殼姿態參考。 | §2.2、§2.4 |
| 分析方法 | PCA校準、陀螺5 Hz低通積分，假設首尾同站姿而扣線性漂移；比較ROM平均差及Wilcoxon、Bonferroni α=0.007。 | §2.4–2.5 |

## 結果

- 步行Slow Gait校準膝矢狀ROM平均差−3.67±5.51°；所有校準的膝冠狀ROM均有差異，Calf Raise to Squat達16.58±6.68°。（§3.1、Table 2）
- Overhead Squat除Slow Gait外的校準，膝矢狀ROM差11.47–14.92°。此為有符號ROM差，不是波形RMSE。（§3.2、Appendix A）

## 限制與閱讀評析

- 健康便利樣本、任務最佳代表試次及首尾姿勢假設，限制居家與患者推廣。（§2.1、§2.3–2.4、§4；reviewer-inference）

完整試次末端用來校正漂移，屬批次後處理；作者的3°實務界限不能直接變成IRMS通過線。

本篇尚未進行逐項品質評讀；全文摘錄不是正式偏誤評分。

## IRMS 工程推論

以下是專案推論，不是原文直接驗證 IRMS 的結果。

- V06 比較時區分因果與使用試次終點的非因果處理，保留所有成功與失敗試次。
- C04／V05 按動作與平面驗證；校準在步行表現較好，不能保證深蹲或轉向亦相同。
