# Clinician perceptions of a prototype wearable exercise biofeedback system for orthopaedic rehabilitation: a qualitative exploration.

來源：[PMID-30366919](../sources/PMID-30366919.md)；摘錄日：2026-10-04。

[原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6224760/) · [原始 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6224760/fullTextXML)

## 核心判讀

十位臨床人員對原型的看法可支持需求設計，不能證明客觀臨床效益。

## 研究事實與定位

| 欄位 | 摘錄 | 原文位置 |
|---|---|---|
| 研究設計 | 單一私立醫院便利樣本，示範前後半結構訪談，主題分析。 | Methods／Participants、Experimental procedure、Data analysis |
| 族群與樣本 | 10 人，6 女／4 男，36.5±9.06 歲；4 位物理治療師及其他護理／骨科／職能人員。沒有病人參與。 | Participants、Patient and public involvement |
| 設備與取樣 | 單顆脛部 Shimmer、Android 平板、Bluetooth；示範計次、技巧與進度。 | Prototype exercise biofeedback system |
| 實驗程序 | 每人一次約一小時，原型只示範一次，沒有長期實際照護部署。 | Experimental procedure、Limitations |
| 參考系統 | 匿名逐字稿及研究者主題分析，非角度真值或客觀照護結果。 | Data analysis、Limitations |
| 分析方法 | 兩位研究者持續比較與交叉檢查主題，分歧討論；沒有量測效應量。 | Data analysis |

## 結果

- 關注客製化、準確度、資訊理解、資料保護及警示責任；正向影響屬受訪者預期。（Results／Opportunities and challenges、Challenges）

## 限制與閱讀評析

- 單院樣本、單次示範、無病人參與及長期結果，不能代表所有照護者。（Discussion／Limitations；author）

需求與可接受性證據，不能當成有效性試驗；研究者及展示情境可能影響表述。
