# Lower Limb Kinematics Using Inertial Sensors during Locomotion: Accuracy and Reproducibility of Joint Angle Calculations with Different Sensor-to-Segment Calibrations.

來源：[PMID-32012906](../sources/PMID-32012906.md)；摘錄日：2026-10-06。

[原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7039222/) · [原始 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC7039222/fullTextXML)

## 核心判讀

校準動作與參考框架影響誤差；同次校準重複不是拆下重戴或跨日信度。

## 研究事實與定位

| 欄位 | 摘錄 | 原文位置 |
|---|---|---|
| 研究設計 | 比較四類功能校準（步行含三速度）與兩種座標建立法，測步行、越障、上下階。 | §2.3–2.5 |
| 族群與樣本 | 7 位健康成人，6 女／1 男，22.6±1.5 歲。 | §2.1 |
| 設備與取樣 | 7 顆 x-IMU，128 Hz、加速度±6 g／陀螺±2000°/s；Vicon 八相機200 Hz，四標記固定在每個 IMU 外殼。 | §2.2 |
| 實驗程序 | 功能校準前後各三次；自選步行校準僅前後兩次。固定在皮膚或衣物，步行5 m，越28 cm障礙或20 cm階。 | §2.2–2.3 |
| 參考系統 | 參考為外殼剛性標記的方向，非獨立骨／解剖標記；光學可使用同一功能校準。 | §2.2、§2.4 |
| 分析方法 | Mahony六軸融合、PCA軸，RMSE／ΔROM／DRIFT與重複校準ICC、SEM；同資料選較佳校準後再評其他任務。 | §2.4–2.5 |

## 結果

- 排除 squat 校準後，步行平均RMSE：骨盆<2°、髖／踝<3°、膝<4°；限定外殼參考與指定校準。（§3.1、Table 2）
- 不同校準重複的矢狀面平均ICC 0.96–0.99；下降階或越障部分RMSE可達13°。（§3.2–3.3、Tables 3–4）

## 限制與閱讀評析

- 7位年輕健康者、短試次、外殼標記參考；動作依賴與固定偽影不能等同人體解剖角效度。（§2.1–2.3、§4；reviewer-inference）

未拆下重戴的校準重複不能作V02重戴信度；以共同參考／處理得到的低誤差需保留限定。

本篇尚未進行逐項品質評讀；全文摘錄不是正式偏誤評分。

## IRMS 工程推論

以下是專案推論，不是原文直接驗證 IRMS 的結果。

- V02 分開校準重複、拆下重戴與跨操作者；逐次保留設定與失敗。
- V01外殼角與V05解剖角分開，不能直接套用本文步行<4°作驗收門檻。
