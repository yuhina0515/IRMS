# Wearable Sensor-Based Exercise Biofeedback for Orthopaedic Rehabilitation: A Mixed Methods User Evaluation of a Prototype System.

來源：[PMID-30669657](../sources/PMID-30669657.md)；摘錄日：2026-10-06。

[原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6359655/) · [原始 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC6359655/fullTextXML)

## 核心判讀

兩週使用性很好仍有計次與紀錄問題；SUS 分數不是量測精度或療效。

## 研究事實與定位

| 欄位 | 摘錄 | 原文位置 |
|---|---|---|
| 研究設計 | 單中心混合方法原型評估：15 位膝置換者居家使用兩週、訪談及 SUS／uMARS。 | §2.1、§2.3–2.4 |
| 族群與樣本 | 15 人，9 女／6 男，63±8.32 歲；10 人術後 2–3 天、5 人術後至少六週。 | §2.1 |
| 設備與取樣 | 單顆前脛 Shimmer3 IMU、102.4 Hz，±2g／500°/s，Android 平板、Bluetooth。 | §2.2 |
| 實驗程序 | 約 30 分鐘訓練後居家兩週；研究者另訪兩次，提供動作 avatar、計次與技巧提示。 | §2.2–2.3 |
| 參考系統 | 問卷、訪談及應用記錄；沒有同步角度真值或隨機療效對照。 | §2.3–2.4、§4 |
| 分析方法 | SUS／uMARS 均值與 SD、主題分析；依完成 Session 數估計依從性。 | §2.4 |

## 結果

- SUS 90.8±7.8／100，整體 uMARS 4.1±0.39／5；使用者仍回報計次、提示與紀錄問題。（§3.1、Table 2）

## 限制與閱讀評析

- 單一私立醫院、較高教育與社經樣本；效益是使用者感受，未完成真實環境辨識準確度及客觀療效驗證。（§4；author）

短期研究者協助可能影響接受度，沒有對照組不能歸因療效；尚不知長期持續使用。

[品質與外推域的單人逐項評讀](../QUALITY_APPRAISAL.md)。

## IRMS 工程推論

以下是專案推論，不是原文直接驗證 IRMS 的結果。

- V11 同時測任務完成、漏計／誤計與資料保存，不能只用滿意度。
- Session 次數、實際動作次數與動作品質需分別驗證並讓使用者理解。
