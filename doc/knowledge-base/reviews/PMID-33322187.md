# Wearable Inertial Sensors for Gait Analysis in Adults with Osteoarthritis-A Scoping Review.

來源：[PMID-33322187](../sources/PMID-33322187.md)；摘錄日：2026-10-06。

[原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7763184/) · [原始 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC7763184/fullTextXML)

## 核心判讀

72篇OA步態研究涵蓋多種設計與指標；研究數與合計樣本不能視為精度或介入效果的合併證據。

## 研究事實與定位

| 欄位 | 摘錄 | 原文位置 |
|---|---|---|
| 研究設計 | 範疇回顧；六資料庫至2020-06-09，雙人獨立篩選與第三者仲裁；納OA成人步態研究，排除只報步數／活動量。 | §2.1–2.2 |
| 族群與樣本 | 72篇研究，作者合計2159位OA成人；加權平均年齡66歲、女性57%；膝46、髖22、踝7篇可重疊。不能確認跨論文族群皆獨立。 | §3.1、§3.3、Table 2 |
| 設備與取樣 | 感測器／位置各異；常見100 Hz、報告範圍32–2000 Hz，動態量程僅32%研究報告。 | §3.5、Table 2 |
| 實驗程序 | 多為實驗室或受控院外歩行，長度不一；44篇橫斷、21篇縱向，其他信效度研究；不是統一介入。 | §3.4–3.5 |
| 參考系統 | 部分研究有健康對照或參考，但不是全部72篇都有同步光學效度標準。 | §2.1、§3.4、Supplementary Table S1 |
| 分析方法 | 描述分類，未統合效果量；雙人修改CASP12項品質評分，一人擷取兩人核對。 | §2.3–2.4、§3 |

## 結果

- 原回顧品質分類沒有高品質研究；43低、24中等，最低常為樣本數依據；不是本庫重新評分。（§3.2、Table 1）
- 33篇量肢段／關節角，12篇用機器學習；11%附補充資料，沒有補充程式碼。（§3.4、§3.6）

## 限制與閱讀評析

- 缺少free-living、縱向與可重用程式；硬體／指標／族群異質，限制實際臨床或居家推廣。（§4–5；author）

範疇分類能找需求與研究缺口，不能把不同研究的樣本加總或分類正確率當裝置效度或療效。

本篇尚未進行逐項品質評讀；全文摘錄不是正式偏誤評分。
