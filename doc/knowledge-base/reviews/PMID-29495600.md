# Inertial Measurement Units for Clinical Movement Analysis: Reliability and Concurrent Validity.

來源：[PMID-29495600](../sources/PMID-29495600.md)；摘錄日：2026-10-06。

[原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5876797/) · [原始 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC5876797/fullTextXML)

## 核心判讀

有真實拆下重戴與跨日設計；即使矢狀波形相似，絕對偏移仍使Xsens與光學不可直接互換。

## 研究事實與定位

| 欄位 | 摘錄 | 原文位置 |
|---|---|---|
| 研究設計 | 便利健康樣本，兩操作者（肌骨物理治療師／動作科學者）、兩場；同場拆IMU休息至少10分鐘換操作者，光學標記保留。 | §2.1–2.3 |
| 族群與樣本 | 26人完成第一場，35.2±8.4歲；25人回第二場，衣物遮標記後跨場信度24人，跳躍23人；效度25人。 | §3.1 |
| 設備與取樣 | 7顆Xsens MTw2／MVN BIOMECH 60 Hz、10相機Vicon MX3+ 120 Hz；解剖標記Plug-in Gait，trigger同步。 | §2.3–2.4 |
| 實驗程序 | 30秒N-pose，步行約8m、蹲及垂直跳各8次；場距4±3天；每步行試次只取中間一跨步。 | §2.3–2.6、§3.1 |
| 參考系統 | Conventional Gait／Plug-in Gait解剖角與廠商IMU模型，坐標正負不同需反轉冠狀角；標記重戴與IMU重戴範圍不同。 | §2.3–2.5 |
| 分析方法 | 6Hz四階低通、重採樣60Hz與aligndata式膝矢狀訊號時間對齊；單次雙向隨機ICC、SEM與扣均值CMC／線性擬合。主文未明示ICC agreement／consistency。 | §2.5–2.6 |

## 結果

- 跨日矢狀離散指標ICC約0.60–0.95；步行／蹲的跨操作者ICC>0.60、SEM<5°，跳躍可從低至高。（§3.2、Figures 1–4）
- 扣均值後矢狀CMC2>0.90，但非實數CMC的其他平面未報，正文明確兩系統不能互換。（§2.6.2、§3.3、§5）

## 限制與閱讀評析

- 便利健康族群、兩操作者與廠商模型，需跨中心與病變研究；絕對角偏移及時間對齊依賴參考。（§2.1、§2.5、§5；reviewer-inference）
- CMC只報所有值為實數的角度／平面，不能把未報範圍當已證明波形相似。（§2.6.2、§3.3；reviewer-inference）

重戴與操作者流程可作V02設計範例；部分試次缺失、未重新放光學標記與參考對齊須納入分析，SEM界限為作者解讀而非IRMS通過線。

本篇尚未進行逐項品質評讀；全文摘錄不是正式偏誤評分。

## IRMS 工程推論

以下是專案推論，不是原文直接驗證 IRMS 的結果。

- V02 逐場保存裝卸與操作者順序、缺失原因及完整校準設定，不把重復封包當獨立樣本。
- V05 波形與絕對角一致性分開；需要V07原始時間證據才能驗證實時延遲。
