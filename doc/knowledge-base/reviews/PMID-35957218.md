# Three-Dimensional Lower-Limb Kinematics from Accelerometers and Gyroscopes with Simple and Minimal Functional Calibration Tasks: Validation on Asymptomatic Participants.

來源：[PMID-35957218](../sources/PMID-35957218.md)；摘錄日：2026-10-06。

[原始全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9370908/) · [原始 XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC9370908/fullTextXML)

## 核心判讀

整體絕對RMSE 7.5°、扣均值後4.0°；參考與時間對齊後處理都影響部署解讀。

## 研究事實與定位

| 欄位 | 摘錄 | 原文位置 |
|---|---|---|
| 研究設計 | 10人同步量測，站姿、坐姿及自選速度10 m往返步行；原研究另有樣本量估計。 | §2.1、§2.3 |
| 族群與樣本 | 10位無癥狀成人，6男／4女，30.2±6.7歲；一人左大腿感測故障，左側缺失，並非整人刪除。 | §3 |
| 設備與取樣 | 7顆Physilog6S 256 Hz，±16g／±2000°/s；12相機Qualisys 100 Hz；每顆IMU在四標記外殼，另有CGM1.0解剖標記。 | §2.2 |
| 實驗程序 | 每人10–12步行試次；同步棒落地試次，站姿重力、步行PCA軸與坐姿方向修正。 | §2.3、§2.4.3、§3 |
| 參考系統 | 比較解剖標記CGM、外殼cluster與IMU三種結果；參考和各次步行方向／姿態定義須區分。 | §2.4–2.5 |
| 分析方法 | Madgwick beta=0.1；每試次航向修正，約1秒同步誤差另以訊號互相關校正；比較RMSE、centered RMSE、CC與ΔROM。 | §2.4.2、§2.4.5–2.5 |

## 結果

- 全部11類運動學的平均IMU RMSE 7.5°，centered RMSE 4.0°；骨盆前後傾RMSE 14.1±2.8°。這不是膝角專屬平均。（§3、Figures 6–7）
- IMU整體平均ΔROM 6.8°；髖內外旋ΔROM可達27.2±7.4°。（§3）

## 限制與閱讀評析

- 健康小樣本與單側故障；非矢狀面相關較低，絕對角偏移仍大。（§3–4；author）
- 光學輔助時間對齊與逐試次漂移修正不能視為無參考的即時部署性能。（§2.4.5–2.4.6；reviewer-inference）

公開資料入口有助重現，但同試次參考對齊、外殼與解剖標記差異均需保留；centered數字不包含絕對零位誤差。

本篇尚未進行逐項品質評讀；全文摘錄不是正式偏誤評分。

## IRMS 工程推論

以下是專案推論，不是原文直接驗證 IRMS 的結果。

- C10／V05 報告RMSE時明列是否扣均值、時間對齊以及平均哪些角度。
- 不可由臨床標準波形相似推得IRMS絕對角、冠狀／橫斷角或長時段漂移已通過。
