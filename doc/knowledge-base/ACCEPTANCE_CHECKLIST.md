## Zotero

使用 Zotero 的獨立測試 library／profile，避免改動既有研究 library 或觸發雲端同步。這些是公共書目，不需要登入帳號。記錄 Zotero 版本、匯入日期及知識庫 commit。

1. 用 File → Import 匯入 `references.bib`，確認 202 條目；查看 ICC 指引只有 Koo、Li 兩位作者。
2. 抽查 PMID-32545227 的 DOI、作者與年；檢查帶團體作者的引用沒有拆成個人姓／名。
3. 在另一個獨立測試 profile 匯入 `references.ris`，同樣確認 202 條目，期刊、卷期、頁碼／文章編號與 DOI 正確。
4. 各匯出一次書目，抽查中文／重音字元、機構作者及多作者。記錄失敗來源 ID 與實際錯誤。
5. 測試用 profile 與匯出留在暫存區；不刪除或合併使用者既有條目。
