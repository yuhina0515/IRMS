內建瀏覽器安全政策阻擋 `file://`；因此本次未完成實際瀏覽器畫面、鍵盤、螢幕閱讀器及不同視窗尺寸驗收。`check_search.js` 是功能邏輯檢查，不是瀏覽器驗收。使用者可直接以自己的瀏覽器開啟 [index.html](index.html)。

官方入口的取得紀錄見 [link-checks.json](data/link-checks.json)。兩份 MPU6050 PDF 直接取得失敗或重新導向，保持 `metadata-only`。本次沒有逐一驗證所有 DOI 網頁的可取得狀態；MED 書目與摘要的身分是以 API 記錄核對。

沒有全面擷取全文、樣本數、效應量或逐篇偏誤風險，沒有完成系統性回顧，也沒有執行人體、原生 App、BLE、OTA 或硬體試驗。[來源方法](SOURCE_METHOD.md) 與 [驗證計畫](VALIDATION_PLAN.md) 說明後續採用數值及建立 IRMS 性能證據的需要。
