內建瀏覽器安全政策阻擋 `file://`；因此本次未完成實際瀏覽器畫面、鍵盤、螢幕閱讀器及不同視窗尺寸驗收。`check_search.js` 是功能邏輯檢查，不是瀏覽器驗收。使用者可直接以自己的瀏覽器開啟 [index.html](index.html)。

官方入口的取得紀錄見 [link-checks.json](data/link-checks.json)。兩份 MPU6050 PDF 直接取得失敗或重新導向，保持 `metadata-only`。本次沒有逐一驗證所有 DOI 網頁的可取得狀態；MED 書目與摘要的身分是以 API 記錄核對。

已完成 14 篇單人主題導向全文摘錄，其餘來源保持原閱讀層級。沒有完整系統性回顧、獨立雙人擷取或逐篇正式偏誤評分，也沒有執行人體、原生 App、BLE、OTA 或硬體試驗。[來源方法](SOURCE_METHOD.md) 與 [驗證計畫](VALIDATION_PLAN.md) 說明後續採用數值及建立 IRMS 性能證據的需要。

ICC 指引更正關係見 [版本查核](data/full-text-version-audit.json)；全文未取得，未升級閱讀深度。Olsson、Seel 本次 XML、Bowman 的數值疑點保存在各篇 [精讀](FULL_TEXT_REVIEW.md)，未靜默更正。
