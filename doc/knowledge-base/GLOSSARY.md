# 專業術語表

60 個詞彙的工作定義，用於本庫與 IRMS 討論。定義是導讀，非另立臨床標準；細節見對應章節與原始來源。

| # | English | 中文與工作定義 | 容易混淆之處 |
|---|---|---|---|
| 1 | IMU | 慣性量測單元，通常含加速度與角速度感測 | 不一定有磁力計 |
| 2 | Specific force | 比力，加速度計所感測的量 | 不是純運動加速度 |
| 3 | Accelerometer | 加速度計，量測三軸比力 | 動態輸出不能直接當重力 |
| 4 | Gyroscope | 陀螺儀，量測角速度 | 積分會受偏移影響 |
| 5 | Magnetometer | 磁力計，量測磁場向量 | 環境金屬可能干擾 |
| 6 | Gravity vector | 重力方向參考 | 正規化後失去原大小 |
| 7 | Six-axis IMU | 三軸加速度加三軸角速度 | 六個通道不等於六自由度姿態已知 |
| 8 | Degree of freedom | 自由度，模型獨立運動的維度 | 不等於感測軸數 |
| 9 | Heading | 航向，相對水平參考的方向 | 六軸通常缺少無條件絕對航向參考 |
| 10 | Drift | 漂移，估計誤差隨時間累積 | 不是一次性零位偏差 |
| 11 | Bias | 偏移／偏差，需說明是感測或統計偏差 | 與隨機噪聲不同 |
| 12 | ODR | 輸出資料率，感測器內部資料更新頻率 | 不等於 App 接收率 |
| 13 | Sampling rate | 採樣率，每秒取得樣本數 | 設定值與實際間隔需分開 |
| 14 | Nyquist frequency | 奈奎斯特頻率，均勻採樣率的一半 | 不是保證所有更低頻內容皆無誤差 |
| 15 | Aliasing | 混疊，頻率成分因採樣而錯置 | 事後平滑無法一般性補回 |
| 16 | DLPF | 數位低通濾波，限制部分頻率內容 | 有效頻寬與延遲均需核對 |
| 17 | Complementary filter | 互補濾波，融合不同頻段資訊 | 權重語意取決於實現 |
| 18 | Kalman filter | 卡爾曼濾波，結合模型與不確定性估計 | 不是無條件最佳 |
| 19 | Quaternion | 四元數，旋轉表示法 | 表示法不證明姿態已可觀測 |
| 20 | Rotation matrix | 旋轉矩陣，座標轉換表示 | 需先定義方向與參照系 |
| 21 | Euler angles | 歐拉角，按旋轉序列分解 | 順序不同結果不同 |
| 22 | Singularity | 奇異／退化條件，參數或量測失去辨識能力 | 數值穩定不代表物理可觀測 |
| 23 | Circular mean | 圓形平均，適用角度周期 | 179° 與 −179° 不應線性平均到零 |
| 24 | Shortest-arc difference | 最短弧差，環形角度的最短帶符號差 | 不是直接實數相減 |
| 25 | Sensor-to-segment | 感測器到肢段的座標對齊 | 不只是站姿歸零 |
| 26 | Static calibration | 靜態校準，利用已知靜止姿勢 | 未必辨識完整關節軸 |
| 27 | Functional calibration | 功能校準，利用運動或限制辨識 | 不同演算法所需激發不同 |
| 28 | Anatomical calibration | 解剖校準，使用骨性標記／參考 | 標記本身也可能有誤差 |
| 29 | Hinge joint model | 鉸鏈關節模型，近似單軸旋轉 | 人體膝不完全符合 |
| 30 | Observability | 可觀測性，能否從輸入辨識狀態 | 不等於圖面能顯示 |
| 31 | Excitation | 激發，為參數辨識提供足夠變化 | 靜止或單一退化動作可能不足 |
| 32 | Soft tissue artifact | 軟組織偽影，皮膚／組織相對骨的運動 | IMU 與光學都可能受影響 |
| 33 | Kinematic crosstalk | 運動學串擾，軸錯置導致跨平面混入 | 小角度結果可能是對齊誤差 |
| 34 | ROM | 活動范圍，角度變化範圍 | 不等於絕對姿態或完整功能 |
| 35 | Kinematics | 運動學，描述位置、姿態與運動 | 不直接描述力 |
| 36 | Kinetics | 動力學／力學負荷，如力與力矩 | 不能只由膝角直接取得 |
| 37 | MAE | 平均絕對誤差 | 與 RMSE 對大誤差的權重不同 |
| 38 | RMSE | 均方根誤差 | 需要有定義明確的參考 |
| 39 | Centered RMSE | 中心化 RMSE，扣除平均偏移後比較 | 會隱藏絕對零位誤差 |
| 40 | Agreement | 一致性，方法輸出的接近程度 | 相關不是一致性 |
| 41 | ICC | 組內相關係數，依模型描述信度 | 必須報告形式與信賴區間 |
| 42 | SEM | 量測標準誤，描述誤差尺度 | 依模型與資料而定 |
| 43 | MDC | 最小可偵測改變 | 超過它不自動代表臨床重要 |
| 44 | MIC / MCID | 最小重要改變／差異 | 需特定族群、終點與情境 |
| 45 | Confidence interval | 信賴區間，反映估計不確定性 | 不是個別誤差的保證範圍 |
| 46 | Biofeedback | 生物回饋，把量測資訊回傳給使用者 | 量測、理解與療效不同 |
| 47 | Retention | 保留，經過時間后維持學到的表現 | 不是訓練當下表現 |
| 48 | Transfer | 轉移，把學習效果用於其他情境 | 需獨立測試 |
| 49 | Adherence | 依從性，是否按約定完成程序 | 登入次數不等於完成訓練 |
| 50 | PROM | 患者回報結果量測 | 與客觀感測功能可以互補 |
| 51 | GATT | BLE 通用屬性架構，組織服務與特徵 | 服務存在不代表資料已保存 |
| 52 | ATT MTU | ATT 傳輸單元上限，決定單筆協定承載 | 要扣操作碼等開銷，且需協商 |
| 53 | Notification | 無 ATT 逐筆確認的特徵值通知 | 不代表沒有下層機制，也非持久化確認 |
| 54 | Indication | 具有 ATT 確認的特徵值指示 | 確認不等於臨床或應用語意驗證 |
| 55 | Monotonic clock | 單調時鐘，適合耗時與積分 | 與日期／時區時鐘用途不同 |
| 56 | WAL | 預寫日志，SQLite 交易保存機制之一 | 備份仍需處理活躍 WAL |
| 57 | Transaction | 交易，一組原子完成的資料操作 | 記憶體已收到不等於已提交 |
| 58 | Ed25519 | EdDSA 的簽章方案 | 簽章證明來源完整，不證明功能正確 |
| 59 | Data leakage | 資料洩漏，測試資訊進入訓練或調參 | 重疊視窗與同受試者常造成問題 |
| 60 | Reproducibility | 可重現性，依資料、設定與流程重建結果 | 可重跑不等於結果正確或可泛化 |
