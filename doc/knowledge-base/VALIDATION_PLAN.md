## 分層與資料包

每份資料至少附：App／韌體 commit 與版本、裝置型號、任務、操作者、佩戴條件、校準設定、協定路徑、原始可取得訊號、參考來源、共同時間對齊、缺失規則及試次標記。若缺少原始三軸訊號，需明確說明不能重跑完整融合。

校準完整的鉸鏈路徑、兩向量相容路徑及舊角度路徑應分開呈現；不得合併平均后掩蓋相容路徑的誤差。矢狀、冠狀與橫斷平面的結論，以及健康與患者結果也需分開。研究樣本以受試者為獨立層級，不以封包數取代樣本數。

## 通過標準的決定

技術允許誤差應由用途、參考性能、誤判代價及可偵測改變需求事前決定，不能把其他系統的「5°」直接當作 IRMS 的普遍通過線。可先估計誤差分布與程序失敗原因，再制定版本明確的接受標準。

正式介入研究另需匹配目標族群、比較服務與主要功能終點；樣本數應依效應與不確定性估計，不任意指定。使用 [SPIRIT 2025](sources/PMID-40294593.md) 規劃及 [CONSORT 2025](sources/PMID-40228499.md) 報告。此計畫不改變既有 release gate，也不將 App 單元測試列為人體驗證。
