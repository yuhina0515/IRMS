# Feasibility of using inertial sensors to assess human movement.

[關節軸與無磁力計估計](../topics/hinge.md)

- 原始入口：[來源](https://pubmed.ncbi.nlm.nih.gov/19632882/)

- 閱讀深度：`abstract`；查核：`metadata-and-abstract-retrieved`

## 重點

初期慣性感測可行性研究提供人體運動量測案例；可行性本身不能替代完善的參考對照驗證。

## IRMS 用途

用於關節軸、六軸可觀測性與相對角估計的替代方案研究；先比較機械平臺再進行人體測試。

## 適用限制

理想鉸鏈、磁環境與資料激發條件可能與人體不同；六軸不能保證任意動作下完整三維姿態可觀測。

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
