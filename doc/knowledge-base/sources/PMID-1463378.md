# Electrogoniometric feedback: its effect on genu recurvatum in stroke.

[膝過伸與伸直範圍](../topics/hyperextension.md) · [生物回饋與動作學習](../topics/feedback.md)

## 重點

中風後膝過伸 26 人分為對照與實驗組，兩階段各 4 週：第一階段實驗組在物理治療外加電子量角器回饋，第二階段兩組都只接受物理治療；實驗組過伸減少較多，第二階段差異達顯著（U = 40，p = 0.011）。

## IRMS 用途

以角度感測即時回饋改善過伸的早期對照研究，支持把過伸當作可回饋的目標。

## 適用限制

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
