# Inertial Sensor-to-Segment Calibration for Accurate 3D Joint Angle Calculation for Use in OpenSim.

## 重點

將肢段校準整合到 OpenSim 工作流程，提供模型、感測與光學參考之間對齊的實作案例。

## IRMS 用途

對照 calibration.ts 與 angleMath.ts 的佩戴校準；規劃重戴、不同操作者及校準失敗條件。

## 適用限制

校準方法、肢段與任務需逐篇比對；IRMS 的靜態向量程序不等同所有功能軸辨識方法。

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
