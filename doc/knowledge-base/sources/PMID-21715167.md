# Quantification of inertial sensor-based 3D joint angle measurement accuracy using an instrumented gimbal.

[姿態融合與濾波](../topics/fusion.md)

## 書目與原始來源

Brennan A, Zhang J, Deluzio K, et al.. 2011. Quantification of inertial sensor-based 3D joint angle measurement accuracy using an instrumented gimbal. Gait & posture. 34. 320-323. https://doi.org/10.1016/j.gaitpost.2011.05.018.

- 原始入口：[來源](https://pubmed.ncbi.nlm.nih.gov/21715167/)
- 類型：`publication`；研究形式：`research-study-design-not-extracted`
- 閱讀深度：`abstract`；查核：`metadata-and-abstract-retrieved`
- 證據定位：Abstract; metadata from Europe PMC MED record

## 重點

以儀器化轉臺量化三維關節角精度，提供人體測試前先驗證感測器與演算法的方法。

## IRMS 用途

用於韌體姿態融合、偏移與動態加速度分析；以相同原始訊號、延遲條件比較候選濾波器。

## 適用限制

姿態精度不等於關節角精度；量測硬體、採樣、動作、調參與因果延遲仍需在 IRMS 測試。

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
