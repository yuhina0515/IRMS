# Functional calibration procedure for 3D knee joint angle description using inertial sensors.

[佩戴與肢段校準](../topics/calibration.md)

## 書目與原始來源

Favre J, Aissaoui R, Jolles BM, et al.. 2009. Functional calibration procedure for 3D knee joint angle description using inertial sensors. Journal of biomechanics. 42. 2330-2335. https://doi.org/10.1016/j.jbiomech.2009.06.025.

- 原始入口：[來源](https://pubmed.ncbi.nlm.nih.gov/19665712/)
- 類型：`publication`；研究形式：`research-study-design-not-extracted`
- 閱讀深度：`abstract`；查核：`metadata-and-abstract-retrieved`
- 證據定位：Abstract; metadata from Europe PMC MED record

## 重點

以 IMU 資料進行功能校準，將相對姿態轉成可解讀的三維膝角，並比較校準重複性與參考系統誤差。

## IRMS 用途

對照 calibration.ts 與 angleMath.ts 的佩戴校準；規劃重戴、不同操作者及校準失敗條件。

## 適用限制

校準方法、肢段與任務需逐篇比對；IRMS 的靜態向量程序不等同所有功能軸辨識方法。

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
