# IMU-based joint angle measurement for gait analysis.

## 重點

運用關節運動限制辨識軸與位置，僅用加速度及角速度估計屈伸角；人體與義肢的光學對照誤差不同。

## IRMS 用途

用於關節軸、六軸可觀測性與相對角估計的替代方案研究；先比較機械平臺再進行人體測試。

## 適用限制

原文步態試驗為一位經股截肢受試者，使用 Xsens MTw、光學參考及特定校準；人工關節與人體側的固定條件不同。不能將其精度外推至 IRMS、一般族群或其他動作。

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
