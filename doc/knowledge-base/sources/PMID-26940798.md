# Clinical outcomes of remote asynchronous telerehabilitation are equivalent to traditional therapy following total knee arthroplasty: A randomized control study.

## 重點

非同步遠距服務的隨機研究比較功能、資源使用與滿意度，呈現不同於視訊的模式。

## IRMS 用途

用於完整遠距服務模式的研究背景，分開記錄監督、運動劑量、硬體與療程內容。

## 適用限制

效果屬於完整介入與服務模式，不能推論任何穿戴原型或 IRMS 自動具有同等療效或成本效益。

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
