# Inertial sensor-based feedback can reduce key risk metrics for anterior cruciate ligament injury during jump landings.

## 重點

即時慣性回饋訓練改變部分 ACL 風險相關動作指標；風險指標改善不等同傷害發生率降低。

## IRMS 用途

用於選擇膝部追蹤與功能任務的研究背景；區分 ROM、癥狀、負荷與患者回報。

## 適用限制

關聯、區分病群或追蹤能力不等於診斷能力；角度不能直接給出組織負荷或恢復程度。

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
