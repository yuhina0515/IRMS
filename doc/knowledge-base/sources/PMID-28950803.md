# Changes in gait and plantar foot loading upon using vibrotactile wearable biofeedback system in patients with stroke.

## 重點

中風患者的足底力振動回饋呈現即時步態改變訊號，長期與其他族群效果仍需驗證。

## IRMS 用途

對照 TriggerEngine 與 LED／蜂鳴器回饋，設計理解度、延遲、保留與回饋撤除的評估。

## 適用限制

回饋裝置、疾病與療程差異很大；短期動作改變、滿意度與長期功能改善是不同終點。

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
