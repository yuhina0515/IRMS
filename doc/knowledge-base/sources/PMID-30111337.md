# Validation of wearable visual feedback for retraining foot progression angle using inertial sensors and an augmented reality headset.

## 重點

足進展角的 IMU 加擴增實境視覺回饋可行，提供從量測到可理解回饋的案例。

## IRMS 用途

對照 TriggerEngine 與 LED／蜂鳴器回饋，設計理解度、延遲、保留與回饋撤除的評估。

## 適用限制

回饋裝置、疾病與療程差異很大；短期動作改變、滿意度與長期功能改善是不同終點。

研究族群、樣本數、效應量、完整實驗設定與偏誤風險未全面擷取；正式報告採用數值前須核對原文。
