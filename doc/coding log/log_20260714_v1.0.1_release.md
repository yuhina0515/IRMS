## 🔧 變更內容

1. `package.json`/`package-lock.json` 版本號 1.0.0→1.0.1。
2. `npm run ci`(typecheck+71 tests+build)確認綠後提交、推送。
3. `npm run dist` 重新打包——這次 log 裡**沒有**再出現「default Electron icon
   is used」那行,確認自訂 `.ico` 真的生效了(上次 v1.0.0 打包時圖示還沒做)。
4. 打包後的 `win-unpacked/IRMS Dashboard.exe` 實機啟動測試:Electron 多進程
   架構下同名進程有好幾個,第一次抓到的 PID 沒有視窗標題,但同時間另一個
   PID 正確顯示「IRMS | 智慧復健監測系統」——確認是正常的多進程現象,不是
   打包出問題,不用進一步排查。
5. `gh release create v1.0.1` 從 `main` 建立,附上
   `IRMS Dashboard Setup 1.0.1.exe`,發布說明濃縮為「這次改了什麼」(logo/
   圖示/bar 內縮 + 修的 gitignore 問題),不重複貼 v1.0.0 就有的內容。
