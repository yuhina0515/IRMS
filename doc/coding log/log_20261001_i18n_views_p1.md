# i18n P1 — views and components (2026-10-01)

Branch `feat/i18n-foundation` (PR #21), rebased onto `main` after the adaptive-workbench PR #20. Builds on P0 (dictionary core, `settings.language`, service-layer strings).

## What changed

- All user-visible strings in `src/views`, `src/components`, `App.tsx` and the remaining service messages (`angleRange`, `liveShareHost`, `bluetooth` OTA guards, `modules` activate error, `ModulePanelMount`) now come from `i18n/zh-Hant.ts` (master) / `i18n/en.ts` (`satisfies Messages`). zh-Hant text kept verbatim, so existing zh-pinned tests still pass.
- Settings → Display: language selector (Follow system / 繁體中文 / English). It switches live, no restart. Language names are endonyms and stay untranslated on purpose.
- Dates go through `formatDateTime` with shared presets (`DATE_TIME`, `TIME_SECONDS`, `TIME_MINUTES`); displayed decimals use `formatNumber`. No bare `toLocaleString` is left in the views. (The store's internal log timestamp is unchanged.)
- `startBlocker` returns a machine key (`notCalibrated`, …), not a display string. TopNav and Settings derive connection text from the `connectionStatus` enum via `connectionStatusText()`, so raw English `statusText` no longer shows in zh-Hant either.
- Bold emphasis in long instructions is written `**text**` and rendered by `i18n/rich.tsx`, so each language can put emphasis where its grammar needs it.
- Not localized, as intended: default action names/descriptions seeded into SQLite (`shared/defaults.ts`), CSV headers and metadata keys, stored enums, calibration drift key names (shown raw), module-provided names/tips (P3), Rust strings (P2). `shared/types` labels remain as a legacy reference; the UI no longer reads them. `OTA_ERROR_HINTS` in `shared/protocol.ts` is still zh-only, but nothing uses it.

## Layout (English text)

Screenshots at 360×800 and 1024×600, en and zh baseline, taken with Playwright from a temp dir outside the repo and a stubbed `__TAURI_INTERNALS__`. The language was switched through the real selector.
- Found and fixed: a CJK string hard-coded in CSS (`.v3-history-dur::before { content: '時長 ' }`) that rendered in English. It now uses `attr(data-label)`. The English history rows clipped the "interrupted" badge and the Delete button (reps/ops columns widened). On the narrow history card, Duration overlapped the row buttons (it moved to the top line, which also fixes a zh overlap). The long English trigger chip squeezed the exercise name, so the chip is now fixed-width and the user-chosen name truncates.
- No page scroll in any captured view. Offscreen items are the intentional horizontal strips (settings categories, review summary); they are identical in zh.
- Pre-existing and not caused by i18n: at 360 px the dashboard ruler labels collide when comfort and limit are close (both languages). Some buttons are below 44 px at 1024×600 (desktop layout, same in zh).

- `clinical.segmentKneeHint`, `clinical.history.*` (overComfort, overLimit, demoNote)
- `clinical.calibration.*`: step1Desc, step1Side, tibialCrest, tibialCrestBeside, step2–5 titles/descriptions, step5Display, step5How, sideChanged, step6Desc, coupling, thighDeltaTooSmall, shinDeltaTooSmall, thighPitch, shinPitch, kneeAngle, wizardHint
