# 2026-09-09 變更日誌 — 加入 LICENSE 與免責聲明

> **相關文件**:[[HOME|導覽首頁]]

## 🎯 目的

使用者注意到 IRMS repo 已在 GitHub 公開,但先前沒有 `LICENSE` 也沒有任何免責聲明。
IRMS 是穿戴式復健監測系統,涉及健康/復健情境,若被誤用於實際醫療決策或被他人未經授權
散布,作者缺乏法律上的保護與責任釐清。

## 🔧 動作

1. 與使用者確認兩個屬於個人偏好的決定:授權條款種類、README/LICENSE 是否公開真實身份。
   使用者選擇 **MIT License** + **僅用 GitHub 帳號 yuhina0515**(不公開真實姓名/email)。
2. 新增根目錄 `LICENSE`(MIT,Copyright yuhina0515 2026)。
3. `IRMS_App/package.json` 的 `license` 欄位由 `ISC` 改為 `MIT`,與 LICENSE 一致;
   `IRMS_App_Tauri/package.json` 補上原本缺漏的 `license: MIT` 欄位。
4. README.md 尾端新增兩節:
   - **免責聲明**:明確聲明本專案為教育/展示型專案,非醫療器材,未經臨床驗證,
     感測與判定結果不構成醫療診斷或復健處方,使用風險自負。
   - **授權**:連結 LICENSE,說明 MIT 條款允許自由使用/修改/散布(含商用)但需保留版權聲明。

## 🧠 決策

- 選 MIT 而非 CC BY-NC 或全版權保留:使用者判斷升學備審用途更看重「作品被看見、可被
  審查者/教授自由查閱引用」,MIT 也是備審資料展示最常見的慣例,審查熟悉度高。
- 版權人具名用 GitHub 帳號而非真實姓名:降低真實身份與網路足跡的連結曝光,同時
  GitHub 帳號本身仍具備法律上可追溯的作者身份證明效力。
- 免責聲明措辭聚焦「非醫療器材/不構成醫療診斷」,因為 IRMS 的产品定位(穿戴式復健
  監測)是本專案在健康情境下最主要的潛在風險來源,而非資安或一般軟體品質風險。

## ✅ 驗證

- 確認 `.env` 已在 `.gitignore`(第 4 行)排除且從未被 `git ls-files` 追蹤,公開 repo
  沒有既有的機密外洩問題。
- 讀取修改後的 `README.md`、兩份 `package.json`、新建的 `LICENSE`,確認內容與欄位皆
  正確落地(未另外執行自動化測試,純文件/中繼資料變更)。
