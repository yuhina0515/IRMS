# AI Coding Log - 2026-06-11 03:05:38

## 目的 (Objective)
記錄 IDE 燒錄 ESP32 韌體時發生的 COM 埠佔用錯誤，並將其整理為燒錄防範規範，優化 `AI_CODING_RULES.md` 以協助後續開發。

## 動作記錄 (Action Log)

2. **優化 `AI_CODING_RULES.md`**：
   - 在 `AI_CODING_RULES.md` 的「2. ESP32 韌體開發規則」下新增「燒錄與排錯規範 (Flashing & Debugging)」條款，明文規範燒錄前必須確認並關閉佔用該序列埠的應用程式（例如關閉序列監控），防止編譯上傳流程中斷。
